Contributor guide

Who Can Publish

Anyone can read the solutions on this page. To publish, edit, delete, or upload images, you must be a trusted collaborator on tianyiwang9/github-site. Ask Tianyi to add your GitHub account to the repository before you begin.

Do not use Tianyi's token or share your own token with anyone else. Each contributor should use their own GitHub account and their own fine-grained personal access token.

Once your token is saved in your browser, the same controls work for every trusted collaborator: publish, update, edit, delete, upload images, and regenerate the shared TeX file.

Request Access

If you would like to become a trusted collaborator, send Tianyi your name and GitHub account here. Tianyi will use the GitHub account to send the repository invitation.

Set Up Publishing

  1. Log in to GitHub with the account that has collaborator access.
  2. Create a fine-grained personal access token.
  3. For repository access, select only github-site.
  4. For permissions, set Contents to read and write.
  5. Copy the token once. GitHub will not show it again later.
  6. Paste it into the GitHub token box at the bottom of this page and click Save token.

The token is stored only in your current browser. If you switch browsers, clear website data, or the token expires, save a new token.

Write A Solution

  1. Search for the problem number first. If it already exists, use Edit solution on the existing entry instead of posting a duplicate.
  2. Click New solution before starting a different problem.
  3. Fill in the chapter, problem number, date, author, and title. Titles may include inline math such as $X \to Y$.
  4. Write in Markdown and LaTeX. Inline math uses $...$; display math uses \[...\], $$...$$, or standalone environments such as \begin{align*}...\end{align*}.
  5. Use the live preview to check the formatting before publishing.
  6. Click Publish solution. Wait for the synced confirmation before leaving the page.

Diagrams And Images

For quiver diagrams, paste the exported quiver link as a comment directly above the tikzcd code. The page will display the fixed quiver view and keep the LaTeX source in the solution.

To include an image, click Upload image, choose a PNG, JPG, GIF, or WebP file, and wait until the page inserts the Markdown image code into the editor. Then publish or update the solution.

Edit Or Delete

Each published solution has Edit solution and Delete solution buttons. Editing loads the original Markdown/LaTeX source back into the editor. After making changes, click Update solution and wait for the synced confirmation.

What Gets Updated

A successful publish, update, or delete changes the public solutions list and regenerates rising-sea-solutions.tex. Open pages check for new public solutions automatically, but GitHub Pages may take a short time to rebuild.

If syncing fails, your draft should still be visible in your browser. Do not clear browser data; save the text somewhere safe if needed, refresh, and try again.
